# 五域基本面运行说明

## 迁移

```powershell
python -m app.repositories.fundamental up
```

迁移 032 建表；033、034 纠正通用日期先后假设。回滚会删除五域业务记录，必须先完成备份并显式提供
`--allow-data-loss`。

## 每日更新

Prefect deployment：`daily-five-domain-fundamentals`，Asia/Shanghai 每日 19:45，单实例并发。
证券范围由 `APP_SCHEDULE_CODES` 提供。每只证券先更新当前公司档案、行业、股东、主营和辅助记录，
再刷新 Fundamental Agent 四个工具要求的固定窗口：最新三期公司关键指标、最近两个年度与四个独立
季度盈利记录、最近四个季度末资产负债表、最近四个独立季度现金流。所有记录按源版本幂等更新；
业务错误只记录批次状态，不写空数据，也不删除最后一次成功版本。

## 质量约束

- 必须是交易所限定代码。
- 财务报告期必须是季度末。
- 每条记录必须有 `data_date`、原始响应、来源接口、抓取时间和数据版本。
- `payload.values` 禁止二进制浮点和空值占位。
- 业务表追加写且不可变；相同语义重跑不重复插入。
- 文本推断、银行监管专项指标和未通过真实探测的接口不得伪装成直接事实。

## 盈利窗口更新

`--profitability-window` 以指定 `--as-of-date` 为边界，选择最近两个已结束年度和最近四个已结束季度。
运行会先保存累计源记录，再发布带公式和输入版本的单季记录。任一必需期间、利润表或财务指标缺失时，
整次窗口任务失败，不发布部分派生结果。该入口不会清理其他业务域；生产清理必须先备份并使用明确表清单。

## 公司指标、资产负债与现金流窗口

```powershell
python -m app.workflows.fundamental --codes 000001.SZ --fundamental-analysis-window --as-of-date 2026-11-15
```

该入口支持1至30只唯一的沪深交易所限定代码。任一期缺少八项公司关键指标，或现金流缺少经营、
投资、筹资净额时，对应证券的窗口任务失败且不发布残缺业务记录。源原始响应仍会按失败运行留档；
重复运行使用内容版本幂等发布。
